### Focus areas

- **Infrastructure:** Proxmox VE, virtualization, storage (ZFS/EXT4), backup strategies
- **Networking:** VLAN/OVS, WireGuard, BGP (LIXP member), VyOS firewall engineering
- **Security:** CVE tracking, SIEM (Wazuh), kernel mitigation, spyware threat intelligence (IOC blocklists for NSO/Intellexa/Paragon/Candiru)
- **Platform:** Debian/Ubuntu, Fedora, Alpine, FreeBSD — daily driver is a hardened ThinkPad P16s Gen 4
- **Hardware:** HPE ProLiant Gen8/Gen9 (iLO4 fan control, thermal management), Synology NAS, UGREEN NAS, custom kernel builds
